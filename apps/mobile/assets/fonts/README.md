# Geist

Static cuts (Regular 400, Medium 500, SemiBold 600, Bold 700) of Geist, the web app's
font, made from the variable `geist-latin.woff2` that ships with Next.js (fontTools
instancer, Latin subset). Geist is by Vercel and licensed under the SIL Open Font
License 1.1: https://github.com/vercel/geist-font/blob/main/OFL.txt
